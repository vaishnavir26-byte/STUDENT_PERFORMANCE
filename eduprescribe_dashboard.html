Mathematical Formulation

Burnout Vulnerability Index (BVI)

The BVI synthesizes 5 multidimensional behavioral stressors into a standardized continuous index from 0 to 100:

BVI = 100 * [ 0.25*S1 + 0.20*S2 + 0.25*S3 + 0.15*S4 + 0.15*S5 ]
• S1: Substance Coping ((2*Dalc + Walc - 3)/12)
• S2: Social Depletion ((goout - freetime + 4)/8)
• S3: Vitality Deficit ((5 - health)/4)
• S4: Absenteeism Saturation (min(1, absences/20))
• S5: Relational Friction ((5 - famrel)/4)

A BVI cutoff of 40 separates sustainable academic effort from lifestyle depletion.

Optimization Objective

Minimum-Friction Counterfactual Search

For any at-risk student, the engine solves for the minimum behavioral adjustment vector:

min_Δx ||Δx||_w subject to:
1. P(Pass | x + Δx) >= 0.85
2. BVI(x + Δx) <= 38.0
where Δx contains studytime, absences, schoolsup, and goout.

Rather than passive failure alerts, EduPrescribe outputs concrete, achievable stepping-stones.
